# Image Gallery with Lightbox

A responsive image gallery with a lightbox effect, built using HTML, CSS, and JavaScript.

## Features

* Responsive image grid
* Six nature images
* Clickable images that open in a lightbox
* Enlarged image view
* Next and previous navigation
* Close button
* Image captions
* Alt text for accessibility

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Sample Images

The gallery includes six different nature images representing:

* Mountain landscape
* Mountain lake
* Green mountains
* Forest trees
* Snowy mountain
* Nature landscape

## Lightbox

Clicking an image opens it in an enlarged view. Users can navigate between images using the previous and next buttons or close the lightbox using the close button.

## Project Structure

* `index.html` – Gallery structure and lightbox
* `style.css` – Styling and responsive layout
* `script.js` – Lightbox functionality
